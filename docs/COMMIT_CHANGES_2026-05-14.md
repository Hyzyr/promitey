# Полный список изменений к коммиту от 2026-05-14

## API и серверные сценарии

- Добавлена обработка текущей подписки через `/subscription/current` с корректным состоянием, когда backend возвращает `404` и активной подписки нет.
- Ожидаемые ошибки VLESS больше не пробрасываются как падение приложения: отсутствие подписки, непривязанный Telegram и недоступный Marzban показываются как пользовательские сообщения.
- Добавлен proxy-route для скачивания OpenVPN конфигурации по региону: `/api/configs/openvpn/[region]`.
- Добавлена активация промокодов через `/promocode/activate`, включая пробный промокод `TRIAL7DAY`.
- Добавлен общий delayed refresh для успешных dashboard-мутаций: пробный период, промокод, пересоздание VPN, смена региона, привязка Telegram через public code, включение/отключение TOTP.
- Проверено: backend checkout `/billing/checkout` по Swagger пока является заглушкой `501`, поэтому in-app renew не реализован и UI ведет пользователя в Telegram billing.

## Регистрация и вход

- Кнопка регистрации исправлена с логики/текста входа на регистрацию.
- После подтверждения email-кода убран лишний экран успеха.
- Добавлено временное сохранение регистрационных данных в `sessionStorage`, чтобы после подтверждения кода выполнить auto-login.
- После успешного подтверждения регистрации пользователь перенаправляется на `/dashboard`.
- Ошибка неверных учетных данных при входе отображается в форме, без stack trace и без ощущения падения приложения.

## Подписка, trial и промокоды

- Карточка подписки показывает статус, тариф и дату окончания активной подписки.
- Если активной подписки нет, показывается понятное empty-state сообщение.
- Убрано дублирование карточек подписки на странице `/dashboard/subscription`.
- Trial-кнопка показывается там, где у пользователя `usedTrial === false`.
- После успешной активации trial или промокода UI обновляется с небольшой задержкой, чтобы пользователь успел увидеть success-сообщение.
- Renew-кнопки оставлены как переход в Telegram billing, потому что backend checkout еще не реализован.

## Dashboard UI

- Все dashboard-заголовки карточек приведены к единому стилю: `24px`, medium, `neutral-800`.
- Убран `font-roboto` из всего приложения: из root layout, theme token, CSS utility и всех компонентов.
- Вместо Roboto используется существующая Manrope/общая типографика проекта.
- Исправлен импорт `TrialActivationButton` в карточке подписки на локальный импорт, чтобы TypeScript/VS Code корректно резолвили модуль.
- Исправлена строка действий в карточке подписки: `align-center` заменен на корректный `items-center`.
- Убраны raw/лишние styling-значения там, где можно использовать Tailwind token utilities.

## Модальные окна

- Shared `Modal` теперь рендерится через `createPortal` в root-элемент `#popups`.
- Это исправляет проблему, когда модалка pricing/best price card визуально оказывалась внутри карточки или под другими слоями.
- Scroll lock стал более устойчивым: закрытие модалки больше не должно сбрасывать страницу наверх.

## VPN конфигурации

- VLESS модалка показывает QR-код и subscription URL.
- OpenVPN модалка упрощена до вертикального списка стран/регионов.
- Для OpenVPN добавлены регионы `auto`, `fr`, `uk`, `pl`, `us`, `iq`, `ru`, `de`, `nl`.
- В списке OpenVPN добавлены флаги стран и прямые download-ссылки на региональные `.ovpn` файлы.
- `RecreateVpnButton` подключен к `POST /vpn/recreate`, обрабатывает loading, success, generic error и `429 rate_limited`.
- После успешного пересоздания VPN конфигурации UI обновляется с небольшой задержкой.

## Telegram linking

- Telegram-привязка упрощена до одного основного действия через `/link/site-token`.
- Public-code flow убран из основного видимого сценария, чтобы не перегружать UI.
- После успешной привязки через public code серверное состояние обновляется delayed refresh.

## Profile и безопасность

- Добавлен/улучшен блок TOTP в профиле.
- Включение и отключение TOTP обновляют server-rendered состояние после небольшой задержки.
- Смена пароля оставляет пользователя в безопасном flow восстановления/повторного входа.
- Смена email использует отдельную страницу подтверждения и success-переход обратно в профиль.

## Landing page

- Исправлены цены pricing-секции:
  - 1 месяц: `3 €`.
  - 3 месяца: `7.5 €`, скидка `-16.67%`, `2.50 €/month`.
  - 6 месяцев: `12 €`, скидка `-33.33%`, `2.00 €/month`.
  - 12 месяцев: `16 €`, скидка `-55.56%`, `1.33 €/month`.
- Карточка one-month выровнена по размеру с остальными pricing cards.
- Pricing modal теперь открывается поверх всего интерфейса через общий portal modal.
- Benefits video card получила poster и корректное состояние при воспроизведении.
- Testimonials/benefits/connect-guide получили мобильные и iOS/macOS правки плавности и центровки.
- Connect guide теперь переключает изображения по шагам и использует новые assets `public/images/guide/item01.png`, `item02.png`, `item03.png`.
- Dashboard instruction videos используют общий poster `public/images/feedback-video-poster.png`.

- Видео-карточка в инструкции больше не пытается быть основным маленьким плеером.
- Play-кнопка на dashboard-версии центрирована и без hover-анимации увеличения.
- При клике открывается большая video modal для комфортного просмотра.
- Для OpenVPN и VLESS пока используется одинаковое видео и одинаковый poster, как было запрошено.

## i18n

- Новые пользовательские строки добавлены в `messages/en.json` и `messages/ru.json`.
- Добавлены переводы для trial, OpenVPN countries, Telegram linking, ошибок и обновленных dashboard-сценариев.

## Что важно помнить

- Реальный backend renew/checkout отсутствует: Swagger прямо описывает `/billing/checkout` как `501` заглушку.
- Renew сейчас работает только как переход в Telegram billing.
- Полный список OpenVPN серверов backend пока не отдает отдельным endpoint, поэтому UI использует известные country codes из Swagger.
- Для окончательной визуальной проверки все еще желательно пройти iPhone/iPad/macOS Safari, потому что часть задач касалась scroll/touch поведения.
